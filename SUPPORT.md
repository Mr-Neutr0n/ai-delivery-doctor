# Support

AI Delivery Doctor is an early-stage open-source project.

## Use GitHub Issues for

- reproducible bugs;
- missing check types;
- cross-platform problems;
- evidence/reporting issues;
- adapter proposals;
- documentation gaps.

## Before opening an issue

Please include:

- AI Delivery Doctor version/commit;
- OS and Python version;
- sanitized contract;
- expected behavior;
- observed behavior;
- minimal reproduction;
- sanitized output.

Do not post secrets, private endpoints, production credentials, or customer data.

## Scope

The project provides engineering diagnostics and acceptance evidence. It does not provide authorization to probe third-party systems, and it does not replace site-specific security, compliance, or production acceptance processes.
